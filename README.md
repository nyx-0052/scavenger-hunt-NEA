This was my A-Level Computer Science NEA submission 2025-26. I scored a 66/70.

Project overview: It is a gamified school tour designed for my sixth form, Fettes College, aimed at young kids and toddlers visiting the school on open days. They scan QR codes located around the school and answer questions related to it.

Features: There are two access levels, users and admin. The User interface features an in-built QR code scanner, customisable route settings, and an in-built map. The Admin interface features a dashboard, showcasing trends from data collected, and editable design features.

Technologies used: Tomcat (JSP/Servlets)
